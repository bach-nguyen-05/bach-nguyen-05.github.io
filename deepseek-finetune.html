DeepSeek-R1 Fine-Tune and Benchmark NLP

This project involved fine-tuning the DeepSeek-R1 model on a reasoning dataset. Low-Rank Adaptation (LoRA) was used to train the model efficiently, and benchmarking was done with the "biobertscore" model on the held-out portion of the dataset.

Technologies used: Python, PyTorch, Hugging Face Transformers.

Key achievements:

  • Improved accuracy on the benchmark dataset.
  • Optimized the model for faster inference.
  • Exported the post-trained model to GGUF and ran it locally on an Android phone.

Projects

A selection of my work in language models, computer vision, and robotics.

Active Reasoning — Noisy Agentic Interaction Research

An active reasoning system in which text-only LLMs orchestrate strategic multi-turn dialogues with vision-language models to reduce hallucinations in visual question answering, using probabilistic belief updates and an adaptive questioning strategy with Bayesian belief-state tracking. Built with vLLM and PyTorch.

Report on how Transformers and Large Language Models (LLMs) work NLP

A report focused on the architecture of Transformers, motivated by my fine-tuning project. Limitation: it does not yet cover multimodal features or reasoning with reinforcement learning.

Running light-weight LLMs locally on an Android phone Tutorial

A step-by-step guide to running light-weight LLMs locally on Android using Termux, including a discussion of the limitations of iOS support.

DeepSeek-R1 fine-tune on a reasoning dataset and benchmark NLP

A detailed report on fine-tuning the DeepSeek-R1 model on a reasoning dataset, including performance benchmarks and insights into model improvements. The fine-tuning and benchmarking methods, along with project slides, are posted on GitHub.

Animals classifier (Convolutional Neural Network) Computer Vision

An implementation of a convolutional neural network that classifies various animals, covering dataset preparation, model architecture, and performance evaluation.

OpenCV object detection Computer Vision

Real-time object detection using OpenCV, including setup and algorithm selection (Haar cascades and variations). The repository also covers basic operations and manipulations on images and videos.

Autonomous car Robotics

A team project developing an autonomous car system with only two sensors, demonstrating sensor integration and autonomous decision-making. Our team provided the best solution among six teams.

Multimodal LLMs In progress

A work-in-progress project exploring the integration of multimodal features into large language models, aiming to enhance interaction with both text and visual data.

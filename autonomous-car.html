Autonomous Car Robotics

This project was a collaboration between me and three teammates. We were given a vehicle with only two sensors, used to detect color and the distance to the walls.

The task was simple:

  • Given any random map (same area)
  • Reach the yellow line without crashing
  • Return to the green line without crashing
  • Finish within 5 minutes

Our team provided the best solution among six teams. The key features of our algorithm were:

  • Encoding the map as the car moves through it: a matrix is continuously built to remember the map, so we can compare matrices and avoid repeating the same route unless the target color is reached.
  • Each decimal element in the matrix represents a 4-bit binary number, corresponding to the four directions.
  • The matrix is reset once the model reaches the color.

Limitation: with only two sensors, we could not determine the shortest path to the destination from the start.
